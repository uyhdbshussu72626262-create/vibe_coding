# Daynora 三次任务拆分

## 优先级结论

1. **P0 工程与数据基础**：先保证项目可启动、数据模型可迁移、旧计划能导入。
2. **P1 核心体验**：再做自由规划、三栏编辑、完成传送、撤销、回收站和 SQLite。
3. **P2 系统与交付**：最后做天气、托盘、通知、番茄钟、自动更新预留、测试和安装包。

## 第一次任务（当前）

目标：搭好可以继续开发的工程骨架。

- Vite + 原生 TypeScript/HTML/CSS 前端。
- Tauri 2 Windows 桌面壳。
- 任务、目标、分类、设置的数据模型。
- 可替换的数据仓库接口与浏览器临时实现。
- 旧版 12 天计划导入为示例数据。
- 三栏界面、顶部统计、主题/语言基础交互、底部传输带占位。
- 生成基础应用图标。
- 输出依赖下载与放置说明。

验收：`npm install` 后可以执行单元测试、启动 Vite 页面，并在安装 Rust 依赖后启动 Tauri 窗口。

## 第二次任务

目标：完成本地数据层与核心任务体验。

- SQLite 建表、迁移、备份与恢复。
- 任务增删改查、目标、分类、重复规则、子任务。
- 三栏编辑、毛玻璃遮罩、自动保存。
- 勾选完成后的传输带动画、15 步撤销、回收站。
- 拖拽排序、复制、拖动改期。
- JSON / CSV / Markdown 导入导出。
- 中英文、现代复古与黑白主题、Noto Sans SC、Lucide 图标选择。
- 数据加密方案落地：优先做 Windows DPAPI + 字段级 AES-GCM；若你坚持 SQLCipher，再单独处理构建依赖。

## 第三次任务

目标：系统集成与可交付安装包。

- Open-Meteo 天气、城市手动设置、可选 GPS、30 分钟缓存。
- 托盘、关闭最小化、任务提醒与每日总结通知、开机自启。
- 番茄钟全屏翻转时钟，ESC 退出。
- 自动更新能力预留但默认关闭。
- 自动化测试、安装包、便携版、源码压缩包。
- 在目标电脑上进行一次可视化验收。
