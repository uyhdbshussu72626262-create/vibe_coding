# Daynora 问题报告

本目录记录当前版本**已知存在的问题与限制**，用于对外说明与后续排期参考。
这里只是如实记录，不代表软件不可用——日常任务管理、专注计时、AI 对话与计划修改均可正常使用。

## 文件

| 文件 | 内容 |
| --- | --- |
| [known-issues.md](known-issues.md) | 详细问题清单（分类、严重度、影响、可能方向） |

## 问题总览

按影响面排序，严重度分为 高 / 中 / 低：

| # | 问题 | 严重度 |
| --- | --- | --- |
| 1 | AI 联网检索效果不稳定，长尾/中文问题容易答非所问 | 高 |
| 2 | 可选择的模型提供商少，且无法自动获取模型列表 | 高 |
| 3 | 联网检索是"应用代检索"，不是模型自主浏览，也没有多轮检索 | 高 |
| 4 | 需要登录 / 付费墙 / 纯前端渲染的网页抓不到正文 | 中 |
| 5 | AI 没有跨会话记忆，不能重新生成或编辑历史消息 | 中 |
| 6 | 图片附件以 base64 入库，长期使用会让数据库膨胀 | 中 |
| 7 | 专注计时只有倒计时，没有历史统计与正计时 | 中 |
| 8 | 任务重复规则只有 4 种，不支持自定义周期 | 中 |
| 9 | 仅提供 Windows 构建，无云同步与多设备 | 中 |
| 10 | 打包体积偏大、无自动更新、无崩溃上报 | 低 |
| 11 | 缺少端到端 UI 测试与 CI | 低 |
| 12 | 代码仍有继续拆分空间（`src/app.ts` 约 1800 行） | 低 |

> 说明：以上问题本轮**不做修复**，仅记录，便于后续按优先级排期。
