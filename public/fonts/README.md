# Noto Sans SC 字体放置说明

把下载好的字体文件放在本目录，文件名保持为：

```text
NotoSansSC-Regular.woff2
NotoSansSC-Medium.woff2
```

下载来源（选择可商用版本）：

- Google Fonts: https://fonts.google.com/noto/specimen/Noto+Sans+SC
- Noto CJK GitHub: https://github.com/notofonts/noto-cjk

`src/styles.css` 已经按上面的路径声明字体。字体缺失时会自动回退到 `Segoe UI`，不会影响程序运行。
