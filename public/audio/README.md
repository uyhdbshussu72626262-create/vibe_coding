# Daynora 音频资源目录

把下载好的音频文件放在本目录。程序只使用这里的真实音频文件；文件缺失时保持静音，不再播放内置合成音。

建议文件：

```text
mixkit-calm-thunderstorm-in-the-jungle-2415.wav   雨声
felix_blume_household_wall_clock_ticking.mp3      钟表声
mixkit-diving-in-deep-water-1312.wav              专注音乐 / 水下氛围
zapsplat_pack_bell_alarm_clock_mp3/...            倒计时结束提醒
```

推荐下载来源（下载前请确认具体音频的授权范围）：

- Pixabay Audio: https://pixabay.com/music/
- Mixkit: https://mixkit.co/free-sound-effects/
- Freesound: https://freesound.org/
- Zapsplat: https://www.zapsplat.com/

建议搜索词：

- rain ambience
- clock ticking
- calm focus music
- gentle alarm

程序当前使用：

- 雷雨雨声
- 钟表声
- 水下氛围
- ZapSplat 铃声作为倒计时结束提醒
